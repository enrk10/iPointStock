Dónde correr esta app

Este archivo es autónomo (HTML/JS, sin servidor). Para escanear con la cámara del iPhone necesitás alojarlo con HTTPS:

GitHub Pages — subís el archivo a un repo y activás Pages. Gratis y estable para uso diario.

Los datos se guardan automáticamente en el navegador. Para continuar desde otro navegador o dispositivo, usá «Guardar progreso» y luego «Continuar progreso» para importar el respaldo. No se envían datos a ningún servidor.
